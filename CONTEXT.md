# GS Mapeamento — reuniões de grupo

Este contexto descreve os termos de negócio usados para cadastrar grupos, seus horários recorrentes e as atas das reuniões.

## Linguagem

**Grupo**:
Unidade que mantém horários recorrentes e registra atas das reuniões.

**Horário recorrente**:
Dia da semana, hora de início e, opcionalmente, hora de término em que um grupo realiza uma reunião regular. Cada horário é associado a uma plataforma do próprio grupo.

**Plataforma do grupo**:
Provedor de reunião habilitado para um grupo, como Zoom, WhatsApp ou Zello, com seu link e dados opcionais de acesso. Cada grupo mantém no máximo uma plataforma ativa de cada tipo.

**Dados de acesso da plataforma**:
Link obrigatório e, quando aplicável, um ID e uma senha/PIN opcionais. Os dados pertencem à plataforma do grupo e são compartilhados pelos horários associados a ela.

**Ata**:
Registro de uma reunião de um grupo, identificado pelo grupo, data e horário. A ata apresenta o nome do provedor usado, sem registrar o ID ou a senha/PIN do acesso.
